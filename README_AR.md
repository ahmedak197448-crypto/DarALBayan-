# دار البيان لتحفيظ القرءان الكريم وعلومه — 2.1 BLUE

## تنبيه مهم
هذه حزمة مصدر تأسيسية لاختبار رفع المشروع والبناء عبر GitHub Actions، وليست تطبيقًا مكتملًا لإدارة دار حقيقية. لا تدخل بيانات طلاب حقيقية ولا تعتمد عليها في المحاسبة قبل تنفيذ الوحدات الناقصة واختبارها.

## الموجود في الحزمة
- مشروع Android/Kotlin أولي.
- شاشة عربية خضراء وذهبية، وزر «موافق» بلا علامة صح، وزر «خروج» أحمر.
- قائمة تمهيدية لوحدات الطلاب والحلقات والمحفظين والماليات وغيرها.
- سير عمل GitHub Actions لبناء APK تجريبي ورفعه كـ Artifact.
- لا يعتمد سير العمل على وجود ملف `gradlew`؛ يجهز Gradle على خادم GitHub.

## لم ينفذ بعد
قاعدة بيانات فعلية؛ حسابات وصلاحيات آمنة؛ إدارة الطلاب والحلقات والمحفظين؛ الرسوم والإيصالات والرواتب؛ طباعة وتقارير PDF؛ نسخ احتياطي ومزامنة؛ استعادة الحساب؛ رسائل واتساب/SMS؛ تكامل دفع؛ رفع الصور والصوت والفيديو ومراجعة المدير؛ واختبارات شاملة.

## الرفع من الهاتف
1. نزّل ZIP وفك ضغطه إن أمكن.
2. افتح المستودع `https://github.com/ahmedak197448-crypto/DarAlBayan-Quran-App`.
3. اختر `Add file` ثم `Upload files`.
4. ارفع محتويات المجلد لا المجلد الخارجي نفسه؛ يجب أن يظهر `settings.gradle.kts` في جذر المستودع، مع `app` و`.github`.
5. اضغط `Commit changes`.
6. افتح تبويب `Actions`، وانتظر انتهاء التشغيل. بعد نجاحه، افتح التشغيل ونزّل `DarAlBayan-Updated-2_1_BLUE-APK` من قسم Artifacts.

## تعريف النسخة

- applicationId: `com.daralbayan.quran`
- versionName: `2.1-blue`
